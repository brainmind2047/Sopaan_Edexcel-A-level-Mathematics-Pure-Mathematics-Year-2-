# Sopaan · Pure Mathematics Year 2

Interactive learning sheets for every chapter of *Pearson Edexcel A level Mathematics, Pure Mathematics Year 2*,
by Brain & Mind Academy (Sopaan Practice Series).

- `index.html` — home page linking all 12 chapters
- `chapter-01-…html` to `chapter-12-…html` — one self-contained page per chapter: theory notes, and for every learning
  objective a learning sheet, a practice sheet and a 30-minute LO test, plus an LO report.

## Publish with GitHub Pages
1. Upload all files in this folder to the root of a repository (or a folder in it).
2. Settings → Pages → Build and deployment → Source: *Deploy from a branch* → branch `main`, folder `/ (root)` → Save.
3. After a minute the site is live at `https://<your-username>.github.io/<repository-name>/`.

Each student's progress is saved in their own browser (sign in with the same name, roll number and PIN each time,
on the same device and browser).
